## 已冻结的商业边界政策

- **广告/赞助实况**（`R16-Q008`、`R15-Q009`）：在条件下允许——须免费访问内容、不售副本、不转权、署名、不暗示背书、不泄漏未公开材料。
- **收费 GM**（`R16-Q009`）：需标准商业 GM 授权方案，覆盖期限、地区和活动范围。
- **平台商业判定**（`DCA-Q006`）：按实际行为判定——无广告/订阅/付费权益/获客用途时可按非商业处理，否则需授权。
- **成本回收**（`R16-Q010`、`R15-Q011`）：仅限实际成本，不得加价或盈利。
- **捐赠**（`R16-Q011`）：自愿捐赠不得成为内容、席位或特权条件。
- **相同方式共享**（`R16-Q012`）：发布衍生内容应提供足以继续修改的可编辑源。
- **商标**（`R16-Q013`）：内容许可不授予商标权，仅允许事实性兼容/基于说明。
- **署名**（`R16-Q007`）：最低署名含作品、权利人、来源、许可名版本和修改说明。

## 准据法

《未登记》内容许可主准据法为**昆士兰州及适用的澳大利亚联邦法律**，并保留中国大陆不可排除强制法；昆州法院非专属管辖（`DCA-Q005`）。
